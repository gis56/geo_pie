Отрисовка зон санитарной охраны элептической и квадратной формы по заданным 
радиусам и азимуту.

Подготовка данных
-----------------

Необходимо создать точечный слой ``PointGeometry``. Объекты этого слоя будут
центрами зон. Вычисления возможны только в спроектированных системах координат.
Если используемый точечный слой в географических (градусных) координатах, то
для расчетов может быть взята проекция проекта. Если и слой и проект 
не спроецированны, то вычисления производится не будут.

.. important::
   Либо слой, либо проект должен быть в плоской проекции.

В аттрибутивной таблице точечного слоя  должны присутствовать поле Double_
содержащее радиусы пластов.

Ввод данных.
------------

В меню **QGis** выбрать пункт 
:menuselection:`Вектор  --> Мои скрипты --> Пласты пересечения`.
Откроется диалоговое окно:

.. image:: /image/inter_buff.png
   :alt: Зона СО
   :height: 340px
   :width: 417px
   :scale: 80 %
   :align: center
   
Выберите слой со скважинами.
Если в слое есть выделенные объекты, галочка ``только выделенные объекты``
становится доступной.
Выберите поле атрибутивной таблицы содержащий радиусы пластов.
Укажите точность подбора площади буфера пластов пересечения.
